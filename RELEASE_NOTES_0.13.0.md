# gptranslate 0.13.0 — draft release notes

**Status:** Release preparation; this is not a tagged or published release.
**Baseline:** 0.12.0 (first public release, 29 October 2026).

## Highlights

Version 0.13.0 is intended to stabilize the gretl/libgretl and gretl4py
plotting workflows and expand coverage of gnuplot constructs produced by
real contributed gretl function packages. `gp-executor` continues to translate
gnuplot scripts into Python/Matplotlib source; it does **not** run the generated
Python code or render a PNG itself.

### New translation coverage

- **Analytic functions:** named `f(x)` expressions, function-only plot sources,
  `x**2`, and selected piecewise ternary expressions such as
  `(x < 0) ? left : right`. Styled x/y zero reference axes are supported.
  Malformed or unsupported function bodies are rejected rather than executed.
- **Palettes and matrix data:** `NA` matrix values, repeated palette stops,
  and degenerate constant palettes, with regression coverage for BMA jointness
  heatmaps.
- **Geometric and layout details:** mixed data/graph-coordinate rectangles
  (including ARprobit recession bands), legend placement below axes,
  and additional named style and line/dash-loop constructs.
- **Finite `set for` commands:** bounded expansion with positive/negative steps,
  descending ranges, quoted literals, and preserved diagnostics.
- **Selected additional package plots:** improved translation of plotting
  scripts emitted by contributed packages, including real integration cases
  for `BMA`, `nic_gig`, `wstats`, `Threshold_Panel`, and `ARprobit`.

### Display and integration

Generated Python source is display-neutral by default; `--add-show` opts into
`plt.show()`. The gretl4py plot queue remains the caller's responsibility.
`--backend=NAME` allows explicit backend selection, including QtAgg where
supported. The translator neither imports Matplotlib nor manages the Python
GUI event loop at execution time.

## Verification available before release

- **GNU/Linux:** 102/102 Meson regression tests passed on 22 November 2026
  (maintainer-reported).
- **gretl4py integration:** 246/246 reviewed package cases, producing 307
  Matplotlib figures through `priority31` (maintainer-reported).
- **Visual review:** selected figures examined for geometry, legends, palettes,
  bands, and analytic curves. Full pixel equivalence with gnuplot is **not**
  claimed.

## Remaining release gates

- Rebuild and run the complete Meson suite from a clean tree on GNU/Linux.
- Verify current code on Windows and macOS; review backend and queue behavior
  in the corresponding gretl4py environments.
- Review `git status`, changes since 0.12.0, third-party fixture provenance,
  and accidental patch artifacts (`*.orig`, `*.rej`).
- After validation, update `meson.build` and README to the final version,
  finalize this document and CHANGELOG, and tag the tested release commit.

## Scope and limitations

`gptranslate` is designed for the subset of gnuplot generated by gretl/libgretl
and selected contributed packages. It is not a complete gnuplot interpreter.
Unsupported terminal-specific features, advanced expressions and some layout
forms may still require additional work. Successful figure generation does not
establish identical numerical or visual semantics for every possible plot.
